PHASE 0 — 历史回顾
📜

Historian 历史学家

最先运行 · 为所有后续 Agent 提供上下文校准
  • 回顾过去 30 天的交易建议记录
  • 计算每笔交易的实际 P&L（盈亏）
  • 使用贝叶斯方法计算每个 Agent 的可信度评分
  • 生成 Trust Weight（0.5x ~ 1.5x）注入后续所有 Agent
  • 识别系统性偏差："宏观分析师过于看空 20%"
▼ 可信度评分注入所有 Phase 1 Agent

PHASE 2 — 交叉质疑
🔴
Red Team 红队
强制反对 · 不可同意团队共识
  • 每个 LONG 建议 → 构建最强 BEAR case
  • 每个 SELL 建议 → 构建 BULL case
  • 寻找历史上类似设置失败的先例
  • 识别隐藏风险：集中度/流动性/监管
  • 评分置信度：HIGH / MEDIUM / LOW
→ red_team.json
⚡ 跨 Agent 质疑
  • Trader → Fundamental："估值合理但图表建议等待回调"
  • Quant → Sentiment：用数据验证或反驳情绪信号
  • Macro → All：宏观体制约束所有推荐
  • Historian → Risk：提供历史信任权重参考
▼ 质疑报告 + 研究报告 → 风控审查
PHASE 3 — 风险审查
🛡️

Risk Manager 风控经理 VETO 否决权

读取所有 Phase 1 + Phase 2 输出 · 有权否决任何交易
风险指标
  • VaR 95% / 99%（1日）
  • Sharpe / Sortino 比率
  • Beta to S&P 500
  • 最大回撤 Max Drawdown
压力测试
  • 2008 金融危机 (-50%)
  • COVID 崩盘 (-34%)
  • 加息 +200bps
  • 中国硬着陆 · AI泡沫破裂
合规红线： 单仓 ≤10% · 行业 ≤30% · 国家 ≤50% · 默认止损 7% · 默认止盈 15% · 相关性警告 >0.80
▼ 风控通过（或 VETO 否决部分交易）
PHASE 4 — 综合决策
👔

Portfolio Manager 投资组合经理

团队 Lead · 读取所有 Agent 输出 · 产出最终决策
  • 按 Historian 可信度评分加权所有建议
  • 逐一回应 Red Team 质疑（反驳或调整仓位）
  • 解决 Agent 之间的分歧与矛盾
  • 接受 Risk Manager 的 VETO 决定
  • 生成最终《投资备忘录》含异议观点
  • 通知 Historian 记录所有建议用于未来评估

Macro Analyst 宏观分析师

PHASE 1

监控全球宏观经济环境，判定当前市场体制。

  • 跟踪 Fed / ECB / PBoC / BoJ 央行政策
  • 分析收益率曲线（US 2Y/10Y spread）
  • 监控通胀（CPI/PCE）、就业（NFP）
  • 跟踪 DXY、Gold、Oil、VIX、USD/CNY
  • 体制分类：RISK-ON / RISK-OFF / TRANSITION
  • 识别催化剂 · Top 3 宏观主题
📁 macro.json
📈

Quant Researcher 量化研究员

PHASE 1

用定量方法分析市场数据，发现统计异常和因子信号。

  • 动量因子：1M / 3M / 6M / 12M 收益
  • 波动率体制分析（已实现波动率）
  • 均值回归 Z-Score vs 移动均线
  • 构建跨资产相关性矩阵
  • 统计异常检测 · 体制变化识别
📁 quant.json
💰

Fundamental Analyst 基本面分析师

PHASE 1

深入分析公司财务数据和估值模型。

  • 财报分析：收入增长、利润率、FCF
  • P/E, P/S, EV/EBITDA vs 行业均值
  • DCF 折现模型 · 可比公司分析
  • 内部人交易 · 分析师评级修订
  • 评级：STRONG BUY → STRONG SELL
📁 fundamental.json
💬

Sentiment Analyst 情绪分析师

PHASE 1

分析市场心理和资金流向。

  • AI News Digest 新闻情绪分析
  • VIX 水平 · Put/Call 比率
  • ETF 资金流向 · 板块轮动趋势
  • 北向资金监控（港股通）via Longbridge
  • 情绪评分：-1.0（极度恐慌）~ +1.0（极度贪婪）
📁 sentiment.json
🎯

Trader 交易员

PHASE 1

技术分析专家，负责确定精确的交易执行方案。

  • RSI(14) / MACD / Bollinger Bands / StochRSI
  • 支撑位/阻力位 · 枢轴点分析
  • 入场价（LIMIT vs MARKET）· 止损（ATR-based）· 止盈
  • Kelly Criterion / 固定分数仓位管理
  • 整合 TradingView 社区评级
  • 质疑 Fundamental："估值好但等回调"
📁 trader.json

Red Team 红队

PHASE 2

强制反对 — 不可同意团队共识。被授权扮演魔鬼辩护人。

  • 每个 LONG → 构建最强 BEAR case
  • 每个 SELL → 构建 BULL case
  • 搜索历史上类似设置失败的先例
  • 识别隐藏风险：集中度/相关性/流动性/监管
  • 评分置信度：HIGH / MEDIUM / LOW
  • 质疑宏观体制判断
📁 red_team.json
🛡️

Risk Manager 风控经理 VETO

PHASE 3

拥有否决权的风控经理，确保投资组合符合风险参数。

  • VaR 95% / 99%（1日）计算

  • 合规：单仓≤10% / 行业≤30% / 国家≤50%
  • Sharpe / Sortino / Beta / Max Drawdown
  • 整合 Red Team 风险到评估中
  • 有权 VETO 违规交易

3 Agents · ~30-50K tokens · VIX飙升 / 止损触发
🌍 Macro 🛡️ Risk 🎯 Trader
当 VIX 日内飙升 >20%、止损被触发、或市场出现极端波动时自动触发。优先评估风险敞口和对冲策略。

🏛️ FOMC / CPI 响应

4 Agents · ~60-80K tokens · 宏观事件
🌍 Macro 📈 Quant 🛡️ Risk 🎯 Trader
